数据分析框架

定义问题：如果数据科学、大数据、机器学习、深度学习等流行词是解决方案的话，那真正的问题是什么？我们往往急于采用新的技术和算法解决的问题，但是正如谚语所说，不要本末倒置，问题在前，需求在中，解决方案在后。

数据采集：数据泛滥，知识匮乏，大量的数据往往就客观的存在那儿，需要把它们收集起来加以利用。

数据预处理：将原始数据转化为可用数据是必要的。数据整理包括建立架构以存储和处理数据、制定数据处理标准以确保数据质量和控制、数据提取（ETL和网页抓取）、数据清洗以识别异常、缺失和离群点。

探索性分析：利用描述性和可视化方法以查找潜在问题、模式、分类、相关性及数据比较。此外，了解和选择正确的假设检验或数据模型也需要对数据进行分类（即定性与定量）。

数据建模：既可以总结数据，也可以预测未来。算法只是工具，不是万精油，必须知道如何选择合适的工具，如果选择错误的模型，最好的情况下模型性能不佳，最坏的情况下会导致错误结论。

实施和验证模型：在完成模型的训练后，还需要测试模型，这有助于确保模型没有过拟合，也没有让模型过于针对所选模型的子集，以至于无法准确适应同一数据的另一个子集。在这个步骤中，确定模型是过拟合、泛化不足还是适配良好。

模型优化与策略：需要迭代回整个过程，使得模型变得更好、更强、更快。作为数据科学家，策略应该是专注于外包开发运维和应用程序的底层工作，以有更多时间专注于推荐和设计。

  3. 完成对哪些类型的人更有可能生存的分析；
  4. 应用机器学习算法来预测；

6.遇见和欢迎数据

首先了解数据，它们是什么数据类型，哪些是自变量/因变量。首先导入数据，使用sample和info函数进行数据概览，可以看见哪些是定量数据，哪些是定性数据。

  1. Survived：这是标签，即目标函数target，1表示生存下来，0表示死亡，所有其他变量均是特征变量/自变量，需要注意的是，特征越多不代表预测会更好，而是合适的特征。
  2. PassengerID and Ticket：它们是乘客的唯一表示，对预测结果没有影响，所以舍弃它们。
  3. Pclass：表示阶级，是社会经济地位的象征，1表示上层阶级，2表示中产阶级，3表示下层阶级。
  4. Name：是乘客的姓名，包括称呼，可以推断出乘客的性别和工作，以及从姓氏推出家庭规模，从工作推出社会经济地位。
  5. Sex and Embarked：性别和登船口，都是名义性数据，将进行哑变量化便于数据分析。
  6. Age and Fare：年龄和船票，都是连续性数据。
  7. SibSp and Parch：表示家庭兄弟姐妹/配偶人数以及父母孩子人数，可以进行特征工程，创建一个家庭人数规模的新特征。
  8. Cabin：存在许多空值，舍弃。

7.数据清洗4C原则：纠正（Correcting）, 补充（Completing）, 创建（Creating）, 转换（Converting）

将通过以下方式清理数据：1）纠正异常值和离群值，2）补充缺失信息，3）创建新的分析特征，4）将字段转换为正确的格式以进行计算和展示。

纠正： 审查数据发现是否出现任何异常或不接受的数据。我们发现年龄和票价可能存在潜在的异常值，然而它们可能是合理的值，这时需要等待完成探索性分析后，再决定是否将其包含或排除在数据集中。需要注意的是，如果它们是不合理的值，例如年龄=800而不是80，那么现在处理是一个安全的决定。然而，在修改数据原始值时需要谨慎，因为这可能是创建准确模型所必需的数据。

填充：年龄、船舱和登船字段中存在空值或缺失数据。有些算法不知道如何处理空值，会导致出错。而像决策树这样的算法可以处理空值。因此，在开始建模之前修复空值很重要。处理空值有两种常见的方法：（1）删除记录，（2）填充缺失值。不建议删除记录，尤其是大量记录，除非它确实代表了一个不完整的记录。相反，最好填充缺失值。对于定性数据，基本的方法是使用众数填充。对于定量数据，基本的方法是使用均值、中位数或均值加上随机标准差填充。中级方法是根据特定标准使用基本方法；例如，根据等级或票价和SES计算平均年龄或登船港口。然而，在部署之前，应该将更复杂的方法与基础模型进行比较，以确定复杂性是否真正增加了价值。对于这个数据集，年龄将用中位数填充，船舱属性将被删除，登船将用众数填充。后续的模型迭代可能会修改这个决定，以确定它是否提高了模型的准确性。

创建： 特征工程是指使用现有特征来创建新特征，以新的信号来预测结果。对于这个数据集，将创建一个家庭规模特征，看它是否在生存中发挥了作用。

转换： 最后，将处理格式。以分类数据为对象导入算法，使得数学计算变得困难。对于这个数据集，我们将把对象数据类型转换为分类哑变量。

划分数据集

赛题提供的测试文件实际上是用于比赛提交的验证数据。因此，我们将使用sklearn 的 train_test_split 函数将训练数据分为两个数据集；75/25 分割，因为这样可以避免模型过拟合。也就是说，算法对某个给定子集过于具体，以至于无法准确泛化另一个来自同一数据集的子集。我们让算法没有见过将用于测试的数据，这样它就不会通过记忆答案来“作弊”。在后续部分中，我们还将使用 sklearn 的交叉验证函数，这些函数将我们的数据集分为训练集和测试集，用于数据建模比较。

探索性分析

现在数据已经清理完毕，将使用描述性和图形性统计来探索数据，描述和总结变量。在这个阶段，会发现分类特征与目标变量以及彼此之间的相关性。

数据模型

数据科学是一个多学科领域，介于数学（例如统计学、线性代数等）、计算机科学（例如编程语言、计算机系统等）和商业管理（例如沟通、专业知识等）之间。大多数数据科学家来自这三个领域之一，所以往往会偏向于某个学科。然而，数据科学就像三条腿的凳子，没有哪一条腿比其他腿更重要。

机器学习（ML）是教机器如何思考。虽然这个话题和大数据已经存在了几十年，但由于入门门槛降低，它比以往任何时候都更受欢迎，对企业和专业人士都是如此。这既是好事也是坏事。这是好事，因为现在这些算法对更多的人变得可访问，可以解决更多现实世界的问题。这是坏事，因为入门门槛降低意味着更多的人不会知道他们使用的工具，可能会得出错误的结论。这就是为什么不仅要知道该做什么，还要知道为什么要这样做。比如你需要一个十字螺丝刀，结果他们递给你一个平头螺丝刀，更糟糕的是递给你一把锤子。

机器学习的目的在于解决人类的问题。机器学习可以分为：监督学习、无监督学习和强化学习。监督学习是指通过提供包含正确答案的训练数据集来训练模型。无监督学习是指通过提供不包含正确答案的训练数据集来训练模型。而强化学习则是上述两种的混合体，模型不会立即得到正确答案，而是在一系列事件之后通过强化学习来获得。现在正在进行监督机器学习，因为通过提供一组特征及其对应的标签来训练算法。然后希望对同一数据集的新子集进行预测时，能够获得相似的准确度。

有许多机器学习算法，但可以归为四类：分类、回归、聚类或降维，这取决于目标变量和数据建模目标。现在我们专注于分类和回归。可以概括地说，连续型目标变量需要使用回归算法，而离散型目标变量需要使用分类算法。顺便提一句，逻辑回归虽然名字中有“回归”，但实际上是一个分类算法。由于问题是预测乘客是否生还，是一个离散型目标变量，将使用 sklearn 库中的分类算法开始我们的分析。我们将使用在后续章节中讨论的交叉验证和评分指标来评估和比较算法的性能。

交叉验证（Cross-Validation）是机器学习中一种评估模型泛化能力的重要方法，核心目的是通过多次拆分数据、重复训练和测试，减少因单次数据划分随机带来的评估偏差，让模型性能的评估更可靠。

Machine Learning Classification Algorithms:

  • 集成学习
  • 广义线性模型 (GLM)
  • 朴素贝叶斯
  • k最近邻
  • 支持向量机 (SVM)
  • 决策树
  • 判别分析

注意：在数据建模方面，初学者总是会问，“什么是最好的机器学习算法？”对此，初学者必须了解机器学习中的“无免费午餐定理”（No Free Lunch Theorem, NFLT）。简而言之，NFLT 表明，并不存在一种超级算法，在所有情况下都能最好地适用于所有数据集。因此，最好的方法是尝试多种机器学习算法（MLA），调整它们，并针对您的特定场景进行比较。还有一种观点认为，更多的数据比更好的算法更重要。
